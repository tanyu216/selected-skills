# PPTX

## 用途

只要涉及 .pptx / .potx 就用它：新建幻灯片、路演与演示稿，读取和抽取文本，编辑既有演示，合并或拆分幻灯片文件，处理模板。

## 适用 / 不适用

- **适用**：交付 PowerPoint 文件；需要保留母版与版式；从演示稿中抽取内容用于其他用途。
- **不适用**：用 HTML 做演示（用 `design-system` 的 slides 能力）；Word 文档（用 `docx`）。

## 典型场景

- **触发语句**：「做一份 12 页的产品路演」「把这个 .pptx 的内容整理出来」。
- **要点**：先确认页数与版式，再一次性生成；改动既有文件时保留母版。
