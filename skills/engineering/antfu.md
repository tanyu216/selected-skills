# Antfu

## 用途

Anthony Fu 的项目约定与工具链选择：新项目脚手架、ESLint / Prettier 替代方案、monorepo 组织、库发布流程，以及他偏好的配置方式。

## 适用 / 不适用

- **适用**：想按 Anthony Fu 的生态习惯搭项目；在 ESLint、Prettier、unbuild、pnpm 之间做取舍；发布 npm 包。
- **不适用**：团队已有成熟且不同的代码规范；非 JS/TS 项目。

## 典型场景

- **触发语句**：「按 antfu 的配置起一个新库」「这个 monorepo 该用 pnpm workspace 还是 catalog」。
- **要点**：它给的是偏好而非唯一答案，先确认团队是否愿意接受这套约定。

## 注意点

这是上游 14 个 skill 中的总纲条目；`vue`、`nuxt`、`vite`、`vitest` 已单独收录，其余 `pnpm`、`unocss`、`pinia`、`nitro`、`vitepress` 与 `antfu-*` 工作流未单独收录。
