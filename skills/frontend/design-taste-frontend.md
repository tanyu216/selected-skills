# Design Taste (Frontend)

## 用途

给网站定美术方向：从 247 个精选画廊站点（One Page Love、Awwwards 等）提炼出构图、字体、配色、摄影与分区蓝图，并用严格的反 slop 规则和真实浏览器检查器收口。

## 适用 / 不适用

- **适用**：从零做网站或落地页，需要避免模板感；已有页面但「看着普通」，需要重定方向。
- **不适用**：后台、仪表盘等产品界面（用 `interface-design`）；只需要组件实现（用 `daisyui`）。

## 典型场景

- **触发语句**：「这个落地页太模板了」「给我一个有品味的视觉方向」。
- **要点**：先定一个研究方向（idea / composition / type / palette），再用浏览器截图做 look-and-fix 循环。

## 注意点

它强调强风格与反 slop，可能和既有品牌规范冲突；有品牌手册时先服从品牌，再用它做执行。
