# Impeccable

## 用途

对前端界面做最后一公里的打磨：层级、布局、字体、配色、动效、UX 文案、无障碍、响应式与边界状态。也能用于从头设计或整体重做，并支持原生 iOS / Android 界面。

## 适用 / 不适用

- **适用**：界面「能做但不够好」，需要系统化 critique 和逐项修正；落地页、仪表盘、产品 UI、表单、设置页、空状态。
- **不适用**：需要先定品牌或美术方向（用 `design-taste-frontend`）；只需要实现组件库（用 `ui-styling`）。

## 典型场景

- **触发语句**：「把这个页面打磨一下」「审查这页的层级和可访问性」。
- **要点**：先跑 critique 列出问题，再分轮修；每轮改完用浏览器截图复核。

## 注意点

它倾向于主动重构视觉，和既有设计系统一起用时先确认 token 与组件边界，避免把规范改掉。
