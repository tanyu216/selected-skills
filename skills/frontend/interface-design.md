# Interface Design

## 用途

设计、构建、审查和打磨产品型界面：仪表盘、管理后台、SaaS 工具、设置页、数据界面与交互型产品。关注视觉工艺、布局层级、token、状态与设计系统一致性。

## 适用 / 不适用

- **适用**：后台与数据密集界面；需要处理空状态、加载、错误、密集表格等产品态；要求设计系统一致。
- **不适用**：营销页、落地页、活动页与纯品牌工作（它的上游描述明确排除）。

## 典型场景

- **触发语句**：「重新设计这个后台的数据页」「这套表格和筛选器的层级很乱」。
- **要点**：先梳理信息层级与状态矩阵，再动视觉；数据界面优先可读性而不是装饰。

## 注意点

它明确不覆盖营销站；需要强视觉风格时与 `design-taste-frontend` 分工，不要同时当主指导。
