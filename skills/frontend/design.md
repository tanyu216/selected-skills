# Design (ui-ux-pro-max)

## 用途

覆盖面很广的设计技能：品牌识别、设计 token、UI 样式、Logo 生成（55 种风格）、企业识别系统（CIP，50 种交付物）、HTML 演示文稿、Banner（22 种风格）、图标与多平台社交图。

## 适用 / 不适用

- **适用**：需要成套品牌物料或营销视觉；从 Logo、CIP 到社交图一次做完；需要快速产出可交付的 mockup。
- **不适用**：只需要产品界面（用 `ui-ux-pro-max` 或 `interface-design`）；只需要设计 token（用 `design-system`）。

## 典型场景

- **触发语句**：「设计一套 Logo 和品牌基础规范」「做一张发布会 Banner」。
- **要点**：先确认交付物清单和尺寸，再选风格；生成类能力需要对应的图像 API。

## 注意点

Logo、图标等生成能力依赖 Gemini、Atlas Cloud 或 MuAPI 的密钥；没有密钥时退化为纯 SVG / HTML 方案。
