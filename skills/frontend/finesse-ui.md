# Finesse UI

## 用途

按用途路由地构建与打磨高完成度网页界面：品牌站、产品仪表盘与工作流、AI 工作台、电商、H5 / 移动端页面与单个组件。保留项目既有识别度，并审计视觉质量、无障碍与动效。支持苹果风 / editorial / app / spatial 等模式。

## 适用 / 不适用

- **适用**：落地页、作品集、后台、管理面板、H5 页面；需要在既有品牌下把界面做「完整」。
- **不适用**：需要推翻重做品牌方向（用 `design-taste-frontend`）；只需要组件库落地（用 `ui-styling`）。

## 典型场景

- **触发语句**：「这个 H5 看着不完整」「按苹果风把这个页面做精」。
- **要点**：先判定页面用途和项目身份，再选模式；审计项要覆盖键盘、对比度和 reduced-motion。

## 注意点

模式选择会影响整页风格，混用多个模式会失去一致性；与 `impeccable` 功能重叠，二选一作为主流程。
