# Finesse Term

## 用途

把用户说不准的界面描述换成一句能直接发给 Agent 的准确需求，并顺带点出他没叫出名字的术语。内置 142 条本地术语库，覆盖布局、交互、状态、组件、表单、动效、质感、无障碍等。

## 适用 / 不适用

- **适用**：用户用大白话描述网页或 H5 的效果、交互、动效、质感或故障；需要把模糊反馈转成可执行需求。
- **不适用**：需求已经明确、只差实现；需要做视觉设计决策本身。

## 典型场景

- **触发语句**：「鼠标放上去变个色」「底下那条黑杠挡住按钮了」「在微信里打开显示不对」。
- **要点**：照常把活干完，再在结果里自然带出术语和一句大白话解释，不要打断用户先做术语教学。

## 注意点

术语库以中文互联网与移动端语境为主，英文项目或非 Web 平台可能没有对应条目。
