# UI UX Pro Max

## 用途

设计、实现、审查和修复界面时的主入口：页面与组件、设计系统、无障碍、交互、响应式布局、字体、配色与图表。附带可检索的本地数据（风格、产品色板、字体搭配等），用于给出有依据的设计选择。

## 适用 / 不适用

- **适用**：从零设计界面或审查现有界面；需要在多种视觉方向之间做选择；检查无障碍与响应式问题。
- **不适用**：只需要落地某套组件库（用 `daisyui` 或 `ui-styling`）；需要强美术指导的个人风格（用 `design-taste-frontend`）。

## 典型场景

- **触发语句**：「这个后台界面怎么改」「给我三个视觉方向」「检查一下无障碍」。
- **要点**：先定信息架构与产品类型，再从本地数据里挑风格和色板，不要凭感觉配色。

## 注意点

它同时是 `design`、`ui-styling`、`design-system`、`brand` 等子技能的入口；同一项目里只让它担任一次主设计指导，避免和 `impeccable`、`design-taste-frontend` 互相覆盖。
