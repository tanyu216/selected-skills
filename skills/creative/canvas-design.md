# Canvas Design

## 用途

创作原创静态视觉艺术：海报、艺术画面、封面、活动视觉与单页设计物料。流程是先发明一套命名的「设计哲学 / 美学运动」，再用它推导画面，最终产出约 90% 视觉、10% 必要文字的成品——是艺术对象，不是加了装饰的文档。

标准交付是两个文件：一份设计哲学 `.md`，以及单页 `.png` 或 `.pdf`；多页需求用同一哲学做不同变体，打包成一个 PDF 或若干 PNG。

## 适用 / 不适用

- **适用**：海报、艺术画、封面、社交媒体静态视觉；需要原创的视觉方向探索；品牌或活动的单页视觉物料；要求排版与构图达到成品级精度。
- **不适用**：网页、App 或可交互原型（用 `finesse-ui` / `interface-design` / `design-taste-frontend`）；视频与动效；以文字排版为主的正式文档（用 `docx` / `pdf`）；需要可编辑矢量源文件的场景（它只输出 PNG / PDF）。

## 典型场景

- **触发语句**：「做一张海报」「来一张有艺术感的封面」「给这个活动出一张视觉图」「先定一个视觉方向，再出图」。
- **要点**：先写 4–6 段通用的设计哲学（空间与形式、颜色与材质、尺度与节奏、构图与平衡、视觉层级），不要把具体主题写进去；再从需求里提炼一条不直白的隐性引用；最后单页视觉优先、文字克制，字体只用 skill 自带的 `./canvas-fonts`。

## 注意点

- 输出只允许 `.md`、`.pdf`、`.png`；不要顺手产出 SVG、HTML 或可编辑设计源文件。
- 必须原创，不得模仿或复制具体艺术家的作品，避免版权问题。
- 成品要留足页边距，任何文字与图形不得重叠或出血；第二遍只做收敛与精修，不要继续堆元素。
- 验收看的是「看起来像顶级设计师反复打磨过」，而不是元素数量；颜色要收敛成一套有意图的有限调色板。
