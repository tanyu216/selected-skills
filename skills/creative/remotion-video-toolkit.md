# Remotion Video Toolkit

## 用途

用 Remotion + React 做程序化视频的参考工具包：动画与时间控制、CLI / Node / Lambda / Cloud Run 渲染、字幕、3D、图表、文字特效、转场与媒体处理。仓库根目录即 SKILL.md，附带 `rules/` 规则集。

## 适用 / 不适用

- **适用**：写 Remotion 代码时查模式；搭建视频生成流水线；做数据驱动模板。
- **不适用**：需要完整导演流程（用 `frame-smith`）；不用 Remotion 的 HTML 路线（用 `hyperframes`）。

## 典型场景

- **触发语句**：「Remotion 里怎么做字幕和转场」「用 Lambda 渲染这个 composition」。
- **要点**：按 `rules/` 的条目逐条对照，不要只凭记忆写 API。

## 注意点

- 仓库没有 LICENSE 文件，许可证为 `unknown`，商用前需向上游确认。
