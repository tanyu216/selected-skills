# Media Use

## 用途

为成片准备素材：音乐、音效、图片、图标、Logo、配音、数字人、生成视频、转写、抠图、调色与风格化，使用 HeyGen 或免费本地工具，并完成已放置音频的混音。

## 适用 / 不适用

- **适用**：片子缺音乐、缺配音、素材偏暗偏灰；需要统一调色或隐藏素材来源。
- **不适用**：需要生成完整成片（用 `hyperframes` + `frame-smith`）；纯 3D 资产生成（用游戏类资产 skill）。

## 典型场景

- **触发语句**：「给这条片子配乐和配音」「这段素材太暗了，调一下」。
- **要点**：先定素材清单与授权要求，再选生成或检索来源；混音要避免人声与音乐打架。

## 注意点

部分能力依赖 HeyGen 账号与额度；生成素材的商用授权需单独确认。
